## 🚨 TROUBLESHOOTING BY MODEL

### Epson Printers:
**Issue:** Prints garbage characters
**Fix:** Ensure ESC/POS mode is enabled (not OPOS mode)

**Issue:** Won't pair via Bluetooth
**Fix:** Reset printer, hold feed button for 5 seconds

---

### Star Printers:
**Issue:** Not detected via USB
**Fix:** Install Star printer driver from official website

**Issue:** WiFi connection fails
**Fix:** Use Star QuickSetup app (iOS/Android) to configure

---

### Generic/Budget Printers:
**Issue:** Partial commands not recognized
**Fix:** Use "Standard Printer" option instead of thermal

**Issue:** Character set issues
**Fix:** Set character set to `CODE_PAGE_PC437` in ESC/POS commands
