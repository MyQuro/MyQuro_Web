## 🎯 DURING DEMO - QUICK REFERENCE

### If Client Asks...

**"Does it work with Bluetooth?"**
→ "Yes! Click 'Bluetooth Thermal' and select your paired device."

**"What if we don't have thermal printer?"**
→ "No problem! Works with ANY printer - even office printers."

**"What if internet goes down?"**
→ "PDF download works offline. Can print later."

**"Which printer should we buy?"**
→ "Star TSP100 or Epson TM-T20. Both industry standard, $200-300."

**"How much?"**
→ "Printer is $50-500 one-time. No software fees. Paper is $0.50/roll."

### If Something Goes Wrong...

**Bluetooth won't connect:**
→ Say: "Let me show browser printing instead"
→ Click "Standard Printer"

**Print dialog doesn't open:**
→ Say: "Popup might be blocked, let me show PDF"
→ Click "Quick PDF Download"

**Nothing seems to work:**
→ Stay calm
→ Say: "PDF download always works as backup"
→ Click "Quick PDF Download"
→ Show professional PDF
→ Say: "Many restaurants prefer PDF for record-keeping anyway"
